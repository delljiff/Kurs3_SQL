# Поиск информации с подключением БД

Цель проекта заключается в поиске информации о странах и самолетах в базе данных, а именно в таблицах, сформированных из API-данных на основе класса, который работает с базой данных.

## Функционал

Собирает данные из `Nominatim` и `OpenSky API` и сохраняет в PostgreSQL.

 #python
 #postgresql
 #psycopg2
 #requests
 #python-dotenv
 
## Установка и использование

Для работы программы необходимо установить зависимости `poetry`

```
poetry install
```

Для работы с базой данных необходимо создать файл `.env` с параметрами доступа к базе данных PostgresSQL. Пример содержимого файла:

```
POSTGRES_HOST=localhost
POSTGRES_USER=postgres
POSTGRES_PASSWORD=password
POSTGRES_PORT=5432
POSTGRES_DB=postgres
```
Запустить main.py

```
python main.py
```

## Описание файлов

- `main.py` отвечает за запуск и интерфейс программы;
- `config.py` отвечает за работу с python-dotenv и содержит дополнительные данные для работы программы;
- `api.py` собирает информацию и подключается к API-сервисам Nominatin и OpenSky;
- `utils.py` создает базу данных и таблицы, одна из которых на основе данных из API;
- `db_manager.py` содержит класс `DBManager`, который позволяет работать с базой данных PostgresSQL.
